## 1. 总体架构

```
┌──────────────┐      HTTPS/JSON       ┌──────────────────┐      ┌──────────┐
│   前端        │  ←─────────────────→  │   后端 API        │  ←────→ │  MySQL   │
│ 移动端 H5     │   Authorization:      │ (Express+Node)   │ 连接池  │ yuecheng│
│ (Vite+React) │      Bearer <jwt>     │  /api/*          │         │          │
└──────────────┘                       └──────────────────┘         └──────────┘
                     ↑ 另含：后端用服务端密钥调用 DeepSeek 做语义解析（key 不下发前端）
```

- **前端**：**移动端 H5**（Vite + React 18 工程，构建产物由后端托管），自适应真实手机尺寸、不含原型手机外框；视觉与原型 1:1 对齐。token 存 `localStorage`。开发可 `npm run dev`（5173），生产访问 `http://localhost:4000/` 同源无跨域。
- **大模型**：语音转文字用浏览器原生 ASR；语义结构化由后端调用 **DeepSeek**（`DEEPSEEK_API_KEY` 仅存服务端 `.env`，接口需 JWT）。
- **后端**：Node + Express，`/api` 下挂载 `auth / tasks / categories / voice` 四个路由模块。
- **数据库**：MySQL，按用户隔离数据（`user_id` 关联）。

```
    ├── config/

    │   ├── auth.js         # JWT 签发(signToken)、校验(authMiddleware)、管理员(adminMiddleware)

    ├── routes/
    │   ├── auth.js       # 注册/登录/me/改密/换邮箱/绑手机/注销/主题
    │   ├── tasks.js      # 任务 CRUD + 按日期/区间查询
    │   ├── categories.js # 分类 增/删/查（按用户）
    │   └── voice.js      # 文本解析为任务草稿
    ├── util/
    │   ├── deepseek.js   # DeepSeek 语义解析（主通道）
    │   ├── mailer.js     # 邮件发送（Resend API 优先，SMTP 回退）
    │   └── parse.js      # 自然语言 → 任务草稿（启发式兜底）
    └── db/

```

> 路由文件用 `asyncRouter()` 而不是 `express.Router()`。Express 4 不捕获 async
> 处理函数抛出的 rejection，那会变成 unhandledRejection 并**直接终止进程** ——
> 一次 MySQL 连接抖动就能让整个后端下线。

## 3. 数据库设计

数据库名：`yucheng`（Railway 云端），字符集 `utf8mb4`。完整建表语句见 `数据库/schema-full.sql`（与 `init.js` 内嵌一致）。

### 3.1 users（用户）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 自增 |
| phone | VARCHAR(20) UNIQUE | 登录手机号 |
| password_hash | VARCHAR(100) | bcrypt 哈希 |
| nickname | VARCHAR(40) | 昵称 |
| theme | VARCHAR(20) | 主题 key，默认 `sage` |
| created_at | DATETIME | 注册时间 |

### 3.2 categories（自定义分类，按用户隔离）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 自增 |
| user_id | BIGINT FK→users | 所属用户 |
| name | VARCHAR(20) | 分类名 |
| color | VARCHAR(40) | 颜色（hsl），如 `hsl(210,45%,90%)` |
| created_at | DATETIME | 创建时间 |

唯一约束：`(user_id, name)`。删除用户级联删除其分类。

### 3.3 tasks（任务）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 自增 |
| user_id | BIGINT FK→users | 所属用户 |
| date | DATE | 任务日期 YYYY-MM-DD |
| title | VARCHAR(120) | 标题 |
| start | TIME NULL | 开始时间 |
| end | TIME NULL | 结束时间 |
| place | VARCHAR(80) | 地点 |
| cat | VARCHAR(20) | 分类名，默认「其他」 |
| status | TINYINT | 0 待办 / 1 已完成 |
| remind | INT | 提前提醒分钟数；`-1` 不提醒 |
| note | VARCHAR(300) | 备注 |
| repeat_days | VARCHAR(60) | JSON 数组（0=周日..6=周六）；NULL 不重复 |
| created_at / updated_at | DATETIME | 时间戳 |

索引：`(user_id, date)` 加速按日查询。

> **数据约定（前后端一致）**：时间字段以 `HH:MM`（前端）/ `HH:MM:SS`（库）存储；`repeatDays` 以 JSON 字符串落库、前端解析为数组；分类为字符串名（与 `categories.name` 对齐），非外键。

### 3.4 themes（主题字典）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PK | 自增 |
| theme_key | VARCHAR(30) UNIQUE | 主题 key |
| theme_name | VARCHAR(50) | 主题名 |
| description | VARCHAR(200) | 描述 |
| group_name | VARCHAR(20) | 分组：`minimal / soft / texture / dark / retro` |
| preview_bg / preview_card / preview_text / preview_primary | VARCHAR(100) | 预览色值（支持 rgba 与渐变） |
| sort_order | INT | 组内排序 |
| is_active | TINYINT | 是否启用 |

> ⚠️ **历史修复（2026-10-07）**：`preview_card / preview_text / preview_primary` 曾为 `varchar(20)`，
> 会把 rgba / 渐变等长值**静默截断**（iOS 暗黑 `rgba(28,28,30,0.85)` 被截成 `rgba(28,28,30,0.8` 等 3 处），
> 已改为 `varchar(100)` 并修复线上数据。schema 与 `init.js` 两处定义均已同步。
> 主题清单以本表为准（按 `group_name` 分组、`sort_order` 排序），前端不写死数量。

## 4. API 接口

Base：`http://localhost:4000/api`
鉴权：除 `auth/send-code`、`auth/register`、`auth/login`、`auth/themes`、`auth/mail-status`、`health` 外，
均需在请求头带 `Authorization: Bearer <token>`。

### 4.1 鉴权与账号 auth
| 方法 | 路径 | 入参 | 返回 |
|------|------|------|------|
| GET | /auth/mail-status | — | `{mode:'api'\|'smtp'\|'none', ok}` 邮件服务自检 |
| POST | /auth/send-code | `{email}` | `{ok, emailed}`；邮件未配好时会回传 `code` 方便联调 |
| POST | /auth/register | `{email, code, password, nickname?}` | `{token, user}` |
| POST | /auth/login | `{account, password}`（账号可以是邮箱或手机号） | `{token, user}` |
| GET | /auth/me | —（需鉴权） | `{user}` |
| PUT | /auth/profile | `{nickname?, sign?, avatar?, theme?}` | `{ok, user}` |
| POST | /auth/password | `{oldPassword, newPassword, code}` | `{ok}` |
| POST | /auth/email | `{email, code}` | `{ok, email}` |
| POST | /auth/phone | `{phone, code}` | `{ok, phone}` |
| POST | /auth/delete | `{code}` | `{ok}` |
| GET | /auth/themes | —（**公开**） | `{themes:[{key,name,group,bg,card,text,primary}]}` |
| GET/PUT | /auth/theme | — / `{theme}` | `{theme}` |

> 密码找回走 `send-code` + `password` 两步，没有独立的 forgot-password 接口。
> 改密/换邮箱/绑手机/注销都要邮箱验证码。

### 4.2 任务 tasks（需鉴权）
| 方法 | 路径 | 入参 | 返回 |
|------|------|------|------|
| GET | /tasks?date=YYYY-MM-DD | query | `{tasks:[...]}` |
| GET | /tasks/range?start=&end= | query | `{tasks:[...]}`（区间，日历用） |
| POST | /tasks | `{title,date,start?,end?,place?,cat?,status?,remind?,note?,repeatDays?}` | `{task}` |
| PUT | /tasks/:id | 上述字段的子集 | `{task}` |
| DELETE | /tasks/:id | — | `{ok:true}` |

**task 结构（出参）**
```json
{
  "id": 1,
  "date": "2026-10-03",
  "title": "写作业",
  "start": "19:00", "end": "21:00",
  "place": "图书馆", "cat": "学习",
  "status": 0, "remind": 0, "note": "完成数学和英语作业",
  "repeatDays": null
}
```

### 4.3 分类 categories（需鉴权）
| 方法 | 路径 | 入参 | 返回 |
|------|------|------|------|
| GET | /categories | — | `{categories:[{name,color}]}` |
| POST | /categories | `{name, color?}` | `{category}` |
| DELETE | /categories/:name | —（URL 编码） | `{ok:true}`（其下任务归「其他」） |

### 4.4 语音 voice（需鉴权）
| 方法 | 路径 | 入参 | 返回 |
|------|------|------|------|
| GET | /voice/engine | — | `{engine:'deepseek'\|'local'}` |
| GET | /voice/asr/token | — | `{token, endpoint, model, languageCodes, expiresInSeconds}` 一次性临时令牌，每人 20 次/分钟 |
| POST | /voice/parse | `{text, baseDate}` | 见下 |
| POST | /voice/parse-one | `{text}` | `{draft:{...}}` 兼容旧接口 |

> `/voice/asr/token` 未配 `ASSEMBLYAI_API_KEY` 时返回 503，前端据此自动降级到浏览器识别。

`/voice/parse` 的返回带 `intent`，支持**新建／修改／删除**三种意图：

```json
{ "intent": "create", "tasks": [ ... ], "source": "deepseek" }
{ "intent": "update", "changes": [{ "id":1, "title":"...", "desc":"...", "patch":{...} }], "source": "deepseek" }
{ "intent": "delete", "changes": [{ "id":1, "title":"...", "desc":"..." }], "source": "deepseek" }
```

解析是三级回落：**DeepSeek 意图解析 → DeepSeek 纯新建解析 → 本地启发式**
（`util/parse.js`，识别「今天/明天/后天/周X」、时间、地点词）。`source` 字段标明实际用了哪一级。

### 4.5 健康检查
`GET /api/health` → `{ok:true, time:...}`

## 5. 鉴权方案
- 登录/注册成功后，后端用 `jsonwebtoken` 签发 30 天有效 token（`{uid}`）。
- 前端每次请求在 `Authorization` 头携带；`authMiddleware` 校验并注入 `req.userId`。
- 所有数据查询均带 `user_id` 条件，保证用户间隔离。

## 6. 前端方案（Vite + React 的移动端 H5，已落地）

> 用户明确要求：**不能直接套用原型 HTML**，必须用前端技术栈重写；页面要自适应真实手机尺寸，**不显示原型的手机外框**（原型只是给研发看的效果稿）。
> 因此前端为 **Vite + React 18** 工程，构建产物输出到 `frontend/app/dist`，由后端 Express 托管，访问 `http://localhost:4000/` 即为真机尺寸的 H5。

```
frontend/app/               # Vite + React 工程（真正的前端源码）
├── index.html              # viewport-fit=cover，占满真实手机视口，无手机壳
├── vite.config.js          # build.outDir -> dist（供后端托管）
├── public/                 # 静态资源：app-icon.webp / alarm.mp3 / pageflip.mp3
├── src/
│   ├── main.jsx / App.jsx  # 入口；未登录显示引导页/Login，已登录显示三页 + TabBar
│   ├── store.jsx           # Context：主题/用户/任务 + 任务 CRUD（乐观更新+落库）
│   ├── styles/
│   │   ├── tokens.css      # 设计 token：19 套主题写成 [data-theme=xxx] 变量
│   │   ├── app.css         # 响应式布局 + 组件样式
│   │   └── extra.css       # 各主题的背景画与卡片/按钮材质
│   ├── lib/                # api / date / cats / asr / parse / sound / track
│   ├── components/         # Onboarding Icon Sheet Dropdown TabBar TaskCard
│   │                       # EditSheet VoiceSheet ThemeSheet RemindSheet PostponeSheet
│   │                       # ProfileSheet AccountSheets AvatarCropper
│   └── pages/              # Login / Today / Calendar / Mine
└── dist/                   # 构建产物（后端托管，已 gitignore，不提交）
```

**自适应与「无手机外框」**：
- 视口：`width=device-width, viewport-fit=cover, user-scalable=no`，配合 `env(safe-area-inset-*)` 适配刘海与底部手势区。
- 布局：`.app` 用 `100dvh` + flex 列布局，宽度 `100%`（大屏最多 520px 居中收窄），**不再有 390×844 固定手机壳、假状态栏、假 Home 指示条**。
- 主题：仅切换 `<html data-theme>` 一个属性即换整套色板。共 **19 套**，按 `group_name` 分五组
  （极简 / 柔和 / 质感 / 深色 / 复古），选择器按这个分组展示。

**与原型一致的视觉**：卡片、分类色点、备注小字、重复/提醒角标、自绘下拉、麦克风 FAB、底部三页导航均按原型还原，但**代码为组件化重写，不复制原型 HTML/CSS**。

**引导页**：5 屏（品牌 / 语音 / 编辑 / 计划 / 主题），首屏放 APP 图标 + 产品 Slogan
「一句话，让生活有条不紊」（渐入 + 逐字打出），末屏是多台立体手机横向滑动的 carousel。

**语音识别（ASR）**：主路径是 **AssemblyAI 实时流式识别** —— 前端先向 `/api/voice/asr/token`
取一次性临时令牌（120 秒有效），再用 AudioWorklet 采 16kHz PCM、WebSocket 直连上游边流边出字。
永久密钥只在服务端 `.env`，前端拿不到。云端不可用（未配密钥／网络／浏览器不支持 AudioWorklet）时
自动降级到浏览器原生 `SpeechRecognition`，并在界面顶部给出提示；再不行则引导手动输入。

**语义解析的输出规范**：`/api/voice/parse` 返回的 `title` 是**润色后的规范任务名**，
不是用户口述原文；口述里额外的说明（如「带上简历和作品集」）归到 `note` 字段。

**语义解析**：文本经 `POST /api/voice/parse` 送后端，由 **DeepSeek** 结构化为任务草稿；后端不可用时前端用本地启发式兜底。**DeepSeek API Key 只存在于服务端 `.env`，前端拿不到**，且接口需 JWT 鉴权（无 token 返回 401）。该接口按用户限流（30 次/5 分钟）。

## 7. 运行手册

### 7.1 前置条件
- Node.js ≥ 18
- 本机 MySQL 服务已启动（D 盘环境已检测到 MySQL / Navicat / MySQL-Front）

### 7.2 后端
```bash
cd D:\语程\后端
npm install
cp .env.example .env
# 编辑 .env：DB_PASSWORD 填本机 MySQL root 密码
npm run initdb     # 建库建表 + 演示数据（账号 13800138000 / 123456）
npm start          # 启动，默认 http://localhost:4000
```

### 7.3 前端（Vite + React H5）
```bash
cd D:\语程\frontend\app
npm install
npm run dev      # 开发：http://localhost:5173（需后端 4000 已启动）
npm run build    # 构建到 D:\语程\frontend\app\dist，由后端托管

# 访问方式（推荐，同源无跨域）：后端启动后打开 http://localhost:4000/
# 手机真机访问：直接用电脑局域网 IP 访问 http://192.168.x.x:4000（手机与电脑同一 WiFi）
#              api.js 会自动识别局域网地址并指向 4000 端口的后端
```

> 后端 `index.js` 会优先托管 `frontend/app/dist`（找不到才回落到旧的 `frontend/h5`）。
> 构建产物**不提交进 git**（`.gitignore` 已覆盖），部署时由平台或本地重新构建。

### 7.4 环境变量（.env）
| 变量 | 说明 | 默认 |
|------|------|------|
| PORT | 后端端口 | 4000 |
| DB_HOST / DB_PORT | MySQL 地址 | 127.0.0.1 / 3306 |
| DB_USER / DB_PASSWORD | MySQL 账号 | root / 空 |
| DB_NAME | 库名 | yuecheng |
| JWT_SECRET | JWT 签名密钥 | 请改为随机长串 |
| MAIL_API_URL / MAIL_API_KEY | 邮件服务（Resend） | 需自行配置 |
| MAIL_FROM | 发件人 | 语程 \<no-reply@你的域名\> |
| MAIL_SMTP_* | SMTP 回退通道 | 未配 MAIL_API_URL 时生效 |
| DEEPSEEK_API_KEY | DeepSeek 密钥 | 需自行配置 |
| DEEPSEEK_MODEL | 模型名 | `deepseek-chat` |
| ASSEMBLYAI_API_KEY | 实时语音识别密钥 | 需自行配置；不配则语音接口 503、前端降级 |
| CORS_ORIGINS | 跨域白名单（逗号分隔） | 内置线上域名与本地端口 |
