## 1. 产品概述

### 1.1 一句话定位
**用说话代替打字**——用户口述一句话（如「明天下午三点在图书馆开会」），系统自动解析出日期、时间、地点、分类，生成一条结构化日程；同时提供完整的日历视图与任务管理能力。

### 1.2 设计灵感
原型参考 Timely 风格的极简日历应用，采用「手机壳 + 底部三 Tab（今日 / 日历 / 我的）」的信息架构，配色清新（鼠尾草绿为主，支持多套主题）。

### 1.3 核心价值
- **输入快**：语音 / 自然语言解析，免手敲表单。
- **看得清**：今日视图聚合当天日程与待办；日历支持日 / 周 / 月多尺度浏览。
- **管得住**：重复、提醒、顺延、分类、备注一应俱全。

## 2. 目标用户与场景

| 用户 | 典型场景 |
|------|----------|
| 学生 | 上课、作业、健身打卡，按「学习 / 运动」分类，周视图规划一周 |
| 职场人 | 会议、出差、待办，工作日重复提醒，月视图看排期 |
| 自律爱好者 | 习惯打卡（重复任务）、语音随手记 |

**核心痛点**：传统日历 App 新建一条带时间地点的日程要点 5~6 次输入；语程把它压缩成「说一句」。

## 3. 信息架构

```
语程
├── 今日（Today）
│   ├── 日期条（可切换日期 / 回到今天）
│   ├── 当日日程卡片（时间轴 + 地点 + 分类色 + 备注 + 提醒铃铛 + 重复角标）
│   ├── 待办清单（无确定时间的事务）
│   └── 语音添加 FAB（右下角麦克风）
├── 日历（Calendar）
│   ├── 月视图（当月网格 + 每日任务数 / 圆点）
│   ├── 周视图（本周 7 天 + 时间轴）
│   ├── 日视图（单日时间轴）
│   └── 左右翻页（周 / 日）；月视图翻月
├── 我的（Mine）
│   ├── 用户资料（头像 / 昵称 / 手机号）
│   ├── 外观主题（多套配色切换）
│   ├── 提醒中心（所有待提醒任务）
│   └── 账号与安全 / 退出登录
└── 全局弹层
    ├── 语音输入弹窗（录音 → 文本 → 解析预览 → 生成任务）
    ├── 编辑弹层（标题 / 日期 / 时间 / 地点 / 分类 / 提醒 / 重复 / 备注 / 顺延）
    └── 登录 / 注册
```

**导航**：底部 Tab Bar 固定切换「今日 / 日历 / 我的」；卡片点击 → 编辑弹层；右下角 FAB → 语音输入。

| F-04 | 退出登录 | 清除本地 token | P0 |

### 4.2 今日页
| 编号 | 功能 | 说明 | 优先级 |
|------|------|------|--------|

### 4.3 语音 / 自然语言添加
| 编号 | 功能 | 说明 | 优先级 |
|------|------|------|--------|

## 5. 关键交互流程

### 5.1 语音添加任务
```
用户点击麦克风 FAB
  → 语音弹窗打开，开始录音
  → 转写为文本（如「明天下午三点在图书馆开会」）
  → 调 /api/voice/parse 得到草稿
  → 弹窗展示预览（标题/时间/地点）
  → 用户确认/微调 → 调 /api/tasks 保存
  → 回到今日页，卡片出现
```

### 5.2 编辑与保存
```
点击卡片 / 待办 → 编辑弹层
  → 修改字段（含自绘下拉：提醒/重复/分类/顺延）
  → 点击保存 → PUT /api/tasks/:id
  → 列表刷新
```

### 5.3 重复与提醒
- 重复：多选星期，存为 `repeatDays`（0=周日..6=周六）；视图层按规则展开。
- 提醒：存「提前分钟数」(`remind`)，`-1` 表示不提醒；提醒中心聚合。

## 6. 非功能性需求

| 类别 | 要求 |
|------|------|
| 性能 | 列表首屏 < 300ms；下拉/弹层动画 ≤ 300ms |
| 兼容 | iOS / Android 移动端浏览器，视口 390×844 为设计基准 |
| 安全 | 密码 bcrypt 哈希；JWT 鉴权；用户数据按 `user_id` 隔离 |
| 可用性 | 触控目标 ≥ 44×44px；空态 / 加载态 / 错误态齐全 |
| 数据 | 用户数据持久化于 MySQL，前端本地缓存 token 与最近视图 |

## 7. 范围与里程碑

**MVP（本期目标）**
- 账户（注册/登录/退出）
- 今日页（日程 + 待办 + 删除/完成）
- 语音/文本解析添加
- 编辑弹层（基础字段 + 分类 + 提醒 + 重复）
- 日历三视图
- 我的（资料 + 主题 + 提醒中心）

**后续迭代**
- 真实语音转写（ASR）接入
- 大模型解析替换启发式
- 重复任务的自动排程与跳过/结束条件
- 子任务、优先级、搜索、数据导出、云同步
- 推送提醒（服务端定时 + 移动端推送）

## 8. 验收标准（MVP）
1. 新用户可注册并登录；演示账号 `13800138000/123456` 可直接登录。
2. 口述一句话可生成一条带时间地点的日程。
3. 今日页正确聚合当天日程与待办，可完成 / 删除。
4. 编辑弹层四类自绘下拉（提醒/重复/分类/顺延）工作正常，点空白统一关闭。
5. 日历日/周/月三视图数据一致，可翻页。
6. 主题切换实时生效并持久化。
7. 所有写操作经后端落库，刷新后数据不丢。
