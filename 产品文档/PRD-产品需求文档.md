## 一、产品概述

### 1.1 产品定位
**语程**是一款语音驱动的智能日程管理 APP，核心卖点是「说话就能建日程」——用户对着手机说一句话，AI自动解析出时间、事项、地点，一键添加到日历，配合类闹钟的强提醒，帮助用户不遗漏每一件事。

### 1.2 目标用户
- 学生党：课表、作业、考试、作息提醒
- 上班族：会议、deadline、待办事项
- 效率爱好者：喜欢用语音快速记录、追求极简高级界面的用户

### 1.3 核心价值
- **快**：说话比打字快3倍，通勤、抬手就能建日程
- **准**：AI自动解析时间/地点/事项，不随意添加用户没说的内容
- **醒**：到点全屏弹窗+铃声提醒，像闹钟一样不遗漏
- **美**：多套高级主题，默认iOS黑白极简风，简约高级

## 三、核心规则（内测版硬约束）

### 3.1 日程时间规则（最高优先级）
1. **用户没说结束时间/时长，绝对不自动补1小时结束时间**，不设置默认end
2. **编辑任务修改开始时间，绝对不自动绑定/生成结束时间**，结束时间只能用户手动选择
3. 只有用户明确说出结束时间、时长（如「开一小时会」「到三点结束」），才会生成end字段
4. 无结束时间的日程，仅按开始时间触发提醒

### 3.2 闹钟提醒规则
1. 到提醒时间（开始时间 - 用户设置的提前提醒分钟数）自动响铃+弹出全屏提醒
2. 点「知道了」：**立刻停止铃声、关闭弹窗，该任务永远不再提醒**
3. 点「稍后提醒」：立刻停止铃声、关闭弹窗，**5分钟后重新检查任务状态，任务存在且未完成才再次提醒**
4. 点弹窗外部遮罩：同「知道了」逻辑，停铃关闭不再提醒
5. 任务在提醒前被删除、标记完成，自动取消所有提醒，不会弹窗
6. 每个任务默认仅触发一次主提醒，稍后提醒仅一次，不无限循环

### 3.3 语音环境规则
1. 正常手机/桌面浏览器（HTTPS、localhost）：正常使用语音识别功能
2. 微信/QQ/支付宝/飞书等APP内置网页、非HTTPS局域网环境：点击麦克风弹出提示弹窗，说明内测阶段语音功能需在浏览器打开，提供「复制链接去浏览器」按钮，自动复制当前页面链接
3. 不拦截手动输入日程功能，非浏览器环境仍可手动创建任务

## 四、核心流程

### 4.1 新用户首次使用
```
打开APP → 引导页（4屏轻立体动画，展示核心功能、主题效果）
→ 登录/注册页（iOS黑白风）→ 输入邮箱 → 获取验证码（Resend邮件）
→ 设置密码 → 勾选同意用户协议、隐私政策 → 注册成功
→ 自动登录 → 首页（空状态引导点击麦克风）
```

### 4.2 语音添加日程
```
点击底部立体麦克风按钮 → 进入全屏聆听界面（检查环境，非浏览器弹提示）
→ 用户说话 → 实时大字幕显示 → 结束录音
→ DeepSeek AI解析（严格遵循不自动加结束时间规则）
→ 显示日程预览卡片 → 用户确认 → 添加成功 → 首页显示新日程
```

### 4.3 闹钟提醒流程
```
后台每10秒检查当日任务 → 到达提醒时间 → 播放卡通铃声（连续2次）
→ 弹出全屏提醒卡片（显示任务标题、开始时间）
→ 用户操作：
  · 点「知道了」→ 立刻停铃关弹窗，永不提醒
  · 点「稍后提醒」→ 立刻停铃关弹窗，5分钟后检查状态再提醒
```

### 4.4 头像上传裁剪流程
```
点击个人头像 → 选择相册图片 → 进入微信风格裁剪界面
→ 单指拖动图片、双指捏合缩放（流畅丝滑，支持缩小到原图以下）
→ 圆形裁剪框实时预览 → 点确定 → 上传裁剪后头像，无偏移
```

### 5.2 设计原则
1. **登录/注册/引导页默认跟随系统默认主题（iOS黑白极简）**，不固定品牌色
2. 登录后跟随用户手动选择的主题，云端同步
3. 切换主题播放真实翻书页音效
4. 所有主题下的按钮、弹窗必须保证文字/背景对比度，不出现白字白底、黑字黑字

## 六、数据埋点与指标体系

### 6.1 埋点事件清单
| 事件名                     | 触发时机   | 关键参数                  |
| ----------------------- | ------ | --------------------- |
| `app_launch`            | APP打开 | 启动类型、来源               |
| `page_view`             | 切换页面   | 页面标识（today/calendar/mine） |
| `login`/`register`/`logout` | 账号操作 | 登录方式、用户ID             |
| `voice_mic_click`       | 点击麦克风 | 当前环境、是否拦截            |
| `voice_recording_start/end` | 录音开始结束 | 录音时长 |
| `voice_parse_success/fail` | AI解析结果 | 识别任务数、失败原因、耗时 |
| `task_add/edit/delete/complete` | 日程操作 | 操作方式（语音/手动）、任务ID |
| `alarm_ring/snooze/confirm` | 闹钟操作 | 任务ID、是否延后 |
| `theme_change`          | 切换主题   | 旧主题→新主题 |
| `avatar_upload/profile_edit` | 个人信息修改 | 修改字段 |
