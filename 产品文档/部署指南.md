| **Netlify** ⭐推荐 | 100GB带宽/月 | 自动部署、HTTPS、CDN加速、操作简单 | 不能跑后端 | ⭐⭐⭐⭐⭐ |

| 方案 | 免费额度 | 优点 | 缺点 | 推荐指数 |

## 二、前端部署：Netlify

### 适用场景
- React/Vue静态前端项目
- 需要CDN加速和HTTPS
- 内测、Demo展示

### 具体步骤

#### 1. 准备工作
- 代码已推送到GitHub仓库
- 前端项目有 `npm run build` 构建命令

#### 2. 连接GitHub
1. 打开 https://app.netlify.com/
2. 用GitHub账号登录
3. 点 "Add new site" → "Import an existing project"
4. 选择GitHub仓库

#### 3. 配置构建参数
| 配置项 | 填写内容 | 说明 |
|---|---|---|
| 基本目录 (Base directory) | `frontend/app` | 前端项目根目录 |
| 构建命令 (Build command) | `npm run build` | 打包命令 |
| 发布目录 (Publish directory) | `dist` | 构建产物目录 |

#### 4. 环境变量（如果需要）
- 如果前端调用后端API，需要配置API地址
- 例如：`VITE_API_URL=https://你的后端地址.com`

#### 5. 部署完成
- 等1-2分钟构建完成
- 会得到一个 `xxx.netlify.app` 的域名
- 之后每次push代码到GitHub，都会自动重新部署

## 三、后端部署：Railway

### 适用场景
- Node.js后端 + MySQL数据库
- 内测阶段（<200用户）
- 不想自己配置服务器

### 具体步骤

#### 1. 准备工作
- 代码已推送到GitHub
- 后端项目有 `npm start` 启动命令
- 数据库SQL脚本已准备好

#### 2. 连接GitHub
1. 打开 https://railway.app/
2. 用GitHub账号登录
3. 点 "New Project" → "Deploy from GitHub repo"
4. 选择你的仓库

#### 3. 添加MySQL数据库
1. 在项目里点 "New" → "Database" → "Add MySQL"
2. Railway会自动创建一个MySQL实例
3. 等数据库创建完成

#### 4. 配置后端服务
| 配置项 | 填写内容 |
|---|---|
| Root Directory | `后端` |
| Build Command | `npm install` |
| Start Command | `npm start` |

#### 5. 配置环境变量
在Railway的Variables里添加：

| 变量名 | 值 | 说明 |
|---|---|---|
| PORT | `3000` | 后端端口 |
| DB_HOST | Railway自动生成 | MySQL地址 |
| DB_USER | Railway自动生成 | MySQL用户名 |
| DB_PASSWORD | Railway自动生成 | MySQL密码 |
| DB_NAME | Railway自动生成 | 数据库名 |
| JWT_SECRET | 自己随便写一串 | 登录密钥 |
| EMAIL_USER | `你的QQ邮箱` | 发验证码用 |
| EMAIL_PASS | `QQ邮箱授权码` | SMTP授权码 |
| DEEPSEEK_API_KEY | `你的API Key` | AI接口 |

#### 6. 初始化数据库
1. 用MySQL客户端连接Railway的数据库
2. 执行项目里的建表SQL脚本
3. 创建管理员账号

#### 7. 获取后端地址
- 部署完成后，Railway会给你一个 `xxx.up.railway.app` 的地址
- 前端的 `VITE_API_URL` 就填这个地址

## 四、前后端联调

### 1. 修改前端API地址
前端代码里把API地址改成线上后端地址：
```js
const API_URL = 'https://你的后端地址.up.railway.app';
```

### 2. 配置跨域
后端Express里添加CORS：
```js
app.use(cors({
  origin: 'https://你的前端地址.netlify.app'
}));
```

### 3. 测试
- 打开前端网站
- 注册/登录测试
- 语音输入测试
- 数据保存测试

## 五、正式上线方案

当用户量超过200人，需要更稳定的时候：

### 推荐方案：腾讯云轻量服务器
- 配置：2核2G，约60元/月
- 优点：国内访问快、稳定、可自定义
- 需要自己配置：
  - Node.js环境
  - MySQL数据库
  - Nginx反向代理
  - HTTPS证书

## 六、常见问题

### Q: 为什么Netlify部署失败？
A: 检查：
1. 基本目录是否正确
2. 构建命令是否正确
3. 发布目录是否相对于基本目录
4. 有没有装错插件（比如Next.js插件）

### Q: Railway免费额度用完了怎么办？
A:
- 内测阶段用户少，基本用不完
- 不够用的话升级到付费版，$5/月起步
- 或者迁移到自己的服务器

### Q: 前端能调用后端API吗？
A: 可以，但需要：
1. 后端配置CORS允许前端域名
2. 前端API地址改成线上后端地址
3. 都是HTTPS，没有混合内容问题
